# Self-hosted web fonts

These font files were downloaded unmodified from Google Fonts and are served from
this site instead of fonts.googleapis.com / fonts.gstatic.com.

| Family | Folder | Licence |
|---|---|---|
| Inter | `inter/` | SIL Open Font License 1.1 — `inter/OFL.txt` |
| Open Sans | `opensans/` | SIL Open Font License 1.1 — `opensans/OFL.txt` |
| JetBrains Mono | `jetbrainsmono/` | SIL Open Font License 1.1 — `jetbrainsmono/OFL.txt` |

The `@font-face` rules live in `src/app/fonts.css`.
